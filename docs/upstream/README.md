# Upstream Foldkit notes

Foldkit's core, UI, and Vite plugin are vendored into wseffect at `packages/foldkit`, `packages/foldkit-ui`, and `packages/vite-plugin`. The snapshots are reproducible from Foldkit commit `060271955cc2fdd34ddb5e17a64b6662268f79c5`; each package records its provenance and local divergence in `UPSTREAM.md`.

The notes in this directory capture generally useful changes that may be proposed upstream. Upstream PRs are optional: submit a proposal only when it is useful to Foldkit users and fits Foldkit's philosophy. Local delivery does not depend on upstream acceptance. Existing open PRs #1699, #1700, #1703, and #1711 remain unchanged.

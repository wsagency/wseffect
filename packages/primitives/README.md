# @wsagency/wseffect-primitives

Local, JavaScript-only stateful and view primitives for the WSEffect Themes package. Import only the named ESM subpath required by a consumer:

- `@wsagency/wseffect-primitives/checkbox-group`
- `@wsagency/wseffect-primitives/select-position`
- `@wsagency/wseffect-primitives/select`
- `@wsagency/wseffect-primitives/context-menu`
- `@wsagency/wseffect-primitives/range-slider`
- `@wsagency/wseffect-primitives/tooltip-group`

Foldkit and `@foldkit/ui` remain external exact peers at 0.168.0. `@floating-ui/dom` is a direct dependency used only by the ContextMenu subpath. This package is MIT licensed; retain all applicable third-party notices when copying source or CSS.
